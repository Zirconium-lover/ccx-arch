Two rules that carry most of the value of the rest:

1. **State a falsifiable hypothesis and name the measurement that can reject
   it, before writing the code.** Then run it and believe it.
2. **Compare arms at a physically meaningful event, not at whichever
   increment the solver gave up on.** The one time that rule was broken here,
   it inverted a conclusion.
