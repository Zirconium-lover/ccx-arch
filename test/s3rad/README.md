wall.  It contains the mesh, materials, UC6 interface, boundary conditions
and output requests; there are no external `*INCLUDE` files.

## Running

The wrapper records the deck and executable hashes, environment, wall time
and return code:

```sh
CCX_EXE=/path/to/ccx_2.23_pardiso ./test/s3rad/run_s3rad.sh
```

An optional first argument chooses the output directory.  Additional
`NAME=VALUE` arguments override the recorded environment and are written to
`provenance.txt`:

```sh
CCX_EXE=/path/to/ccx ./test/s3rad/run_s3rad.sh /tmp/s3rad-pilot \
    CCX_PATHFOLLOW=1e30 CCX_PATHFOLLOW_COD=2e-6
```

The COD value above is only an example from the Mode-I benchmark.  It is not
a calibrated `s3rad` mixed-mode step.

The committed deck explicitly requests PARDISO.  A SPOOLES copy may be useful
for diagnostics, but must have a different filename and must be reported as a
solver-change experiment rather than the historical baseline.
